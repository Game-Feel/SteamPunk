# Сборка SteamPunk

Minecraft 1.20.1, Forge. Моды, их настройки, ресурспаки, шейдеры и сам загрузчик для Legacy Launcher (папки versions и libraries).

Репозиторий приватный. Скачивать могут участники Game-Feel, отправлять изменения только владелец сборки (PhoenixBodrov).

## Установка (один раз)

1. Прими приглашение в репозиторий (придёт на почту и в уведомления GitHub).
2. Установи [Git for Windows](https://git-scm.com/download/win), все пункты по умолчанию.
3. Скачай сборку командой (вход в GitHub попросят один раз):
   `git clone https://github.com/Game-Feel/SteamPunk.git "C:\games\SteamPunk"`
   Или попроси своего Claude: «склонируй https://github.com/Game-Feel/SteamPunk.git в C:\games\SteamPunk».
4. В Legacy Launcher укажи **папку игры** `C:\games\SteamPunk` и выбери версию загрузчика из этой папки.

## Обновление (один клик)

Закрой игру и дважды кликни `Обновить.cmd`. В папке mods останется ровно то, что в сборке. Твои правки модов и конфигов сохраняются в резерв git stash.

Не синхронизируются и не трогаются: миры, логи, карты, скриншоты, `options.txt` (управление, графика, звук), бинды модов, аккаунты и профили лаунчера.

## Отправка изменений

Только для владельца: изменить моды или конфиги, проверить, что игра запускается, закрыть её и дважды кликнуть `Отправить.cmd`.
